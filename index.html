Actionable world modeling · WorldString

Actionable World Representation

A neural architecture that learns the state manifold of real-world objects as a differentiable digital twin—from point clouds or RGB-D, toward policy and dynamics.

Teaser figure

Qualitative overview: WorldString models diverse articulated motion from keypoint-conditioned state, producing structured geometry and point-level predictions.

Abstract

Recent large models show strong conceptual world modeling, but grounded physical understanding requires representations in which objects are first-class, actionable entities with changing state. We study this setting through a world-model lens that separates dynamic objects from largely static background, and relates canonical shape, sparse structural keypoints, and deformation through a learnable mapping Φu.

We propose WorldString, a fully differentiable pipeline that encodes geometry with learnable embeddings, conditions them on object state via a State Transformer, refines global structure with an Object Transformer, and decodes occupancy with a Voxel Transformer from spatial queries. Trained from point clouds or RGB-D streams, WorldString serves as a versatile building block for physical world models and interfaces naturally with policy learning and neural dynamics.

Contributions (at a glance)

  • WorldString. An actionable representation that learns object-centric digital twins from point clouds or RGB-D video, unifying articulated, skinning, and soft objects under a common keypoint-conditioned formulation.
  • Differentiable three-stage architecture. State → Object → Voxel transformers map from sparse keypoint state to structured latent geometry and explicit 3D occupancy.
  • Interpretable visualization. Surface colors show learned token assignment to regions; an error map highlights mismatches against ground truth (true / false positives and negatives).

Network architecture

Differentiable three-stage design: State Transformer maps keypoint state to latent geometry, Object Transformer refines global structure, and Voxel Transformer decodes occupancy from spatial queries.
